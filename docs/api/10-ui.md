# 10 · UI layer (`@wayfarer/sdk/ui`)

Scripts: `ui/core.js`, `ui/primitives.js`, `ui/search-form.js`, `ui/results.js`, `ui/filters.js`, `ui/offer-details.js`, `ui/itinerary-summary.js`, `ui/traveler-form.js`, `ui/ancillaries.js`, `ui/payment-form.js`, `ui/confirmation.js`, `ui/trips.js`, `ui/account.js`, `ui/price-insights.js`, `ui/styles.css`.

The UI layer is **optional and separate** from the core: it only calls public core APIs, so anything it does can be rebuilt by the host. Builders are headless‑first (state + behaviour + accessibility) with a default DOM renderer that can be overridden per builder (`render`/`templates`) or globally (`ui.registerTemplate`). Styling is via CSS custom properties (`--wf-*`) and BEM classes prefixed `wf-`.

### Common contract

```
build<X>(container: HTMLElement | string, options) → Handle
Handle = {
  el: HTMLElement,
  update(options: Partial<Options>): void,       // re-render with new options
  getValue(): V, setValue(v: V): void,          // form‑like builders
  validate(): ValidationResult,                 // form‑like builders
  setBusy(bool), setError(err | string | null),
  on(event, fn): off, off(event, fn),           // builder‑local events
  focus(), destroy(): void                      // destroy removes DOM, listeners, store subscriptions, timers
}
```
Every builder: **Effects: dom · store subscriptions (auto‑unsubscribed on `destroy`)**, plus the core calls listed per entry. Every builder emits `change`, `submit`, `error` locally and sets `aria-busy` / `aria-live` regions itself.

## 1. `ui/core.js`

#### `createUI(client, { theme?, classPrefix? = 'wf', injectStyles? = true, templates?, icons?, dateFormat?, hour12?, renderer?, portal?: HTMLElement } = {}) → UI`
Bind every builder to a client; optionally inject the stylesheet. Effects: dom (`<style>` / `<link>`).

#### `ui.setTheme(tokens: Record<string, string>) → void` · `ui.setDirection('ltr'|'rtl') → void` · `ui.setDensity('comfortable'|'compact')`
Writes `--wf-*` variables / `dir` on the root. Effects: dom.

#### `ui.registerTemplate(name, fn: (ctx, h) => VNode) → void` · `ui.registerComponent(name, factory) → void` · `ui.setIcons(map) → void`
Override partials (`offerCard`, `segmentRow`, `priceTag`, `badge`, …). Effects: none.

#### `ui.mount(container, node) → void` · `ui.unmountAll() → void` · `ui.destroy() → void`
Effects: dom.

#### `h(tag, props?, ...children) → VNode` · `html\`…\` → VNode` · `render(container, vnode) → void` · `bind(selector, renderFn) → off`
Tiny virtual‑DOM helpers; `html` escapes interpolations; `bind` re‑renders on store changes. Effects: dom.

#### `delegate(root, event, selector, handler) → off` · `focusTrap(el) → release` · `announce(message, politeness?) → void` · `portal(node) → HTMLElement` · `formatters(ui) → { money, time, date, duration }`
Effects: dom.

## 3. `ui/search-form.js`

## 15. `ui/styles.css`

Base stylesheet keyed entirely on `--wf-*` tokens: `--wf-color-primary`, `--wf-color-surface`, `--wf-color-text`, `--wf-color-muted`, `--wf-color-success|warning|danger`, `--wf-radius`, `--wf-space-*`, `--wf-font`, `--wf-font-size-*`, `--wf-shadow`, `--wf-z-modal`, `--wf-breakpoint-*`. Dark theme via `[data-wf-theme="dark"]`, RTL via `[dir="rtl"]`, reduced motion respected. No external fonts or icons.
